# MoonRecur

MoonRecur is an original MoonBit library and CLI for deterministic, bounded
civil-calendar recurrence expansion. It targets reusable scheduling logic rather
than wall-clock timers, cron execution, time-zone conversion, or network calendar
synchronization.

The project is under active local development for the 2026 MoonBit August
Hackathon. Its supported behavior, boundaries, acceptance flows, and originality
review are recorded in [`docs/PROJECT_SCOPE.md`](docs/PROJECT_SCOPE.md).
